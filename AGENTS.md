## Project: Deep Vision Networks

Project that uses pre-trained models to build a terrain classifier. Primarily using L-AVATeD dataset. This model will complement work done in the go2_mjlab repository. Purpose is to create a terrain classifier which will most-likely use its label as an input to a high-level controller. 

### Repo Map
- `src/deep_vision_nets/ResNet` will hold ResNet models.
- `src/deep_vision_nets/YOLO` will hold YOLO models.
- `src/deep_vision_nets/data` will hold data for fine-tuning, etc.
